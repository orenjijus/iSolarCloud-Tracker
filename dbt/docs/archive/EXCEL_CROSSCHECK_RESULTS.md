## Key Points untuk Crosscheck

### 1. Formula Verification

**Database Formula**:
```
power_available_hours = SUM(power_available_ratio) / 12.0
unavailability_hours = SUM(unavailability_ratio) / 12.0
total_hours = power_available_hours + unavailability_hours
availability_percent = (power_available_hours / total_hours) * 100
```

**Pastikan Excel menggunakan formula yang sama!**

### 2. MIT Calculation

**Database**: 
- MIT = 1 jika irradiance > 40 W/m²
- Menggunakan priority: GHI → POA → GHI_FALLBACK

**Excel**: 
- Pastikan threshold sama (> 40 W/m²)
- Pastikan menggunakan sumber irradiance yang sama

### 3. Inverter Count

**Database**:
- PT. MMKI 1.75 MWp: 8-10 inverters (varies by date)
- PT. MMKI 4.292 MWP: 24 inverters
- PT. MMKI 5.7 MWp: 13-17 inverters (varies by date)

**Excel**: Pastikan jumlah inverter sama

### 4. POA Fallback

**Database**: Otomatis menggunakan POA jika GHI tidak tersedia

**Excel**: 
- Jika manual switch terlambat atau miss, akan ada perbedaan
- Database lebih akurat karena otomatis

## Expected Differences

### 1. POA Fallback Timing
