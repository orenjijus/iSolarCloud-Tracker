Cara memakai slide Clarification Meeting (16 Mei 2026)
========================================================

File utama (Marp / Markdown):
  2026-05-16_Clarification_Meeting_Slides.md

PDF (jika sudah di-export):
  2026-05-16_Clarification_Meeting_Slides.pdf

Ringkasan rapat (speaker notes):
  2026-05-16_Clarification_Meeting_Brief.md

Laporan lengkap:
  2026-05-16_Laporan_Masalah_Sistem_MMSR.md

--- Presentasi ---

1) VS Code / Cursor
   - Install ekstensi "Marp for VS Code"
   - Buka file .md → ikon preview Marp → tombol Present / Export

2) Command line (PDF atau PPTX)
   npx @marp-team/marp-cli docs/reports/2026-05-16_Clarification_Meeting_Slides.md -o docs/reports/2026-05-16_Clarification_Meeting_Slides.pdf --no-stdin
   npx @marp-team/marp-cli docs/reports/2026-05-16_Clarification_Meeting_Slides.md -o docs/reports/2026-05-16_Clarification_Meeting_Slides.pptx --no-stdin

3) Salin ke PowerPoint manual
   - Setiap bagian antara "---" = satu slide
   - Judul slide = heading ## atau #

 5. Tiga pilar masalah
