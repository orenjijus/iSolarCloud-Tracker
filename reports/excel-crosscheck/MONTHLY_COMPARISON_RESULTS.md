## Temuan Utama

### 1. Perbedaan Site Count
- Database memiliki lebih banyak site dibanding Excel di beberapa bulan
- Perbedaan terbesar: Agustus 2025 (DB: 15, Excel: 10)
- Kemungkinan penyebab:
  - Excel tidak memasukkan semua site
  - Filter atau kondisi berbeda antara DB dan Excel
  - Site baru yang belum masuk ke Excel

### 2. Perbedaan GHI
- Database umumnya memiliki GHI lebih tinggi dibanding Excel
- Perbedaan terbesar: Agustus 2025 (+43.1%)
- Kemungkinan penyebab:
  - Perbedaan sumber data sensor
  - Perbedaan logika fallback GHI
  - Perbedaan agregasi

### 3. Perbedaan Energy
- Bervariasi, ada yang lebih tinggi di DB, ada yang lebih rendah
- Perbedaan terbesar: Juni 2025 (+19.9%), Februari 2025 (-15.5%)
- Kemungkinan penyebab:
  - Perbedaan perhitungan meter (cumulative vs resetting)
  - Perbedaan site yang dihitung
  - Perbedaan handling issue dates

### 4. Perbedaan PR
- PR di database umumnya lebih rendah dibanding Excel
- Perbedaan terbesar: Agustus 2025 (-10.9%)
- Ini konsisten dengan GHI yang lebih tinggi di DB (PR = Energy / GHI / Capacity)

## Query untuk Investigasi Lebih Lanjut

### 1. Lihat Site yang berbeda per bulan
```sql
-- Jalankan query: dbt/analyses/compare_monthly_excel_vs_db.sql
-- Filter untuk bulan dengan perbedaan besar, misalnya:
WHERE year = 2025 AND month = 8
AND has_significant_energy_diff = TRUE
```

### 2. Lihat site yang ada di DB tapi tidak di Excel
```sql
SELECT DISTINCT site_id, site_name
FROM "MMSR"."mart"."mart_site_performance_monthly"
WHERE year = 2025 AND month = 8
AND site_id NOT IN (
    SELECT DISTINCT site_id 
    FROM "MMSR"."public"."site_monthly_performance_excel"
    WHERE year = 2025 AND month = 8
)
```

### 3. Lihat data harian untuk site yang berbeda
```sql
SELECT 
    date_key,
    site_id,
    site_name,
    daily_energy_mwh,
    daily_ghi_kwh_m2,
    pr_ghi_actual
FROM "MMSR"."mart"."mart_site_performance_daily"
WHERE year = 2025 AND month = 8
AND site_id = 'SITE_ID_YANG_BERMASALAH'
ORDER BY date_key
```

### 4. Cek PR calculation untuk site dengan perbedaan PR besar
```sql
-- Contoh: Garuda Metalindo 1 (November 2025)
SELECT 
    year,
    month,
    site_id,
    site_name,
    daily_energy_mwh,
    daily_ghi_kwh_m2,
    actual_capacity_kw,
    pr_ghi_actual,
    -- Manual PR calculation untuk verifikasi
    (daily_energy_mwh * 1000.0) / NULLIF(daily_ghi_kwh_m2, 0) / NULLIF(actual_capacity_kw, 0) as pr_manual
FROM "MMSR"."mart"."mart_site_performance_monthly"
WHERE year = 2025 AND month = 11
AND site_id = 'ISO_SITE_1458125'
```
